# File upload

Applies to: choosing or dropping files, attachments, imports. Read with: `long-task.md` for imports that process the file.

| Code | Check | Level |
|---|---|---|
| UP-01 | Says which types and sizes are accepted before choosing | Must |
| UP-02 | A button to choose files works everywhere; drag and drop is an extra, with a visible drop area | Must |
| UP-03 | Each file shows its name, size and progress; it can be cancelled | Must |
| UP-04 | A rejected file says why (type, size, count) and the others still upload | Must |
| UP-05 | A failed upload offers Retry for that file | Should |
| UP-06 | Uploaded files can be removed or replaced before saving | Should |
| UP-07 | Images show a preview; documents an icon of their type | Nice |
| UP-08 | Leaving during an upload warns first | Should |
| UP-09 | Long names are cut in the middle so the extension stays visible | Nice |
| UP-10 | Duplicate names: says what will happen (replace, keep both) | Should |
