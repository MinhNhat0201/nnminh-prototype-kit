# Search and filters

Applies to: a search box with results, facets, saved filters. Read with: `table.md` when the results are a table.

| Code | Check | Level |
|---|---|---|
| SR-01 | The search box says what it searches ("Search tasks and projects") | Must |
| SR-02 | Results show the query and the count | Should |
| SR-03 | No results: says what was searched, suggests a fix (spelling, fewer filters) and offers to clear filters | Must |
| SR-04 | Matched words are highlighted in the results | Nice |
| SR-05 | Search as you type waits for a pause and does not jump focus; Enter works too | Should |
| SR-06 | Filters show their current values and counts where useful; applying them does not reset the query | Must |
| SR-07 | Clear one filter, clear all | Must |
| SR-08 | The query and filters are in the URL, so Back, refresh and sharing keep them | Should |
| SR-09 | Recent searches or suggestions, when shown, can be removed | Nice |
| SR-10 | Slow search shows loading in the results area, not a blank page | Should |
| SR-11 | On phones, filters open in a sheet with Apply and the result count | Should |
| SR-12 | A keyboard shortcut to focus search is shown when the app has one | Nice |
