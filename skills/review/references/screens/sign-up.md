# Sign-up

Applies to: creating an account, accepting an invitation, joining a workspace. Not for: signing in (`sign-in.md`).
Read with: `form.md`, `a11y-web.md` W-40–W-47.

| Code | Check | Level |
|---|---|---|
| SU-01 | Asks only what is needed to start; everything else waits until later | Must |
| SU-02 | Password rules are shown before typing and checked while typing, item by item | Must |
| SU-03 | `autocomplete="new-password"`, `email`, `name`, so browsers suggest and save | Must |
| SU-04 | An email already in use says so and offers sign-in or reset, without losing the form | Must |
| SU-05 | Terms and privacy are linked; consent that is optional is a separate, unticked choice | Must |
| SU-06 | An invitation shows who invited you and to what, with the email filled and locked | Should |
| SU-07 | After submit, the next step is clear: check your email (which address, resend, change it) or go straight in | Must |
| SU-08 | A link to sign in for people who already have an account | Should |
| SU-09 | SSO sign-up, when offered, says what will be shared | Should |
| SU-10 | The button shows progress and cannot be pressed twice | Should |
| SU-11 | Errors appear next to the field, not only at the top | Should |
| SU-12 | A choice that cannot be changed later (workspace URL, region) says so before submit | Should |
