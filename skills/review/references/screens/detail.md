# Detail page

Applies to: one record: a task, a customer, an order, a document. Read with: `form.md` when it can be edited in place.

| Code | Check | Level |
|---|---|---|
| DT-01 | The header shows the name, the status and the key facts people check first | Must |
| DT-02 | The main actions sit in the header in a stable order; destructive ones in a menu and confirmed | Must |
| DT-03 | A way back to the list that keeps the list's filters and scroll | Must |
| DT-04 | Fields are grouped and labelled; empty fields show "Not set" or are hidden by one rule across the app | Should |
| DT-05 | Who changed what and when (activity or history) when the record is shared | Should |
| DT-06 | Long content (descriptions, comments) wraps and can be read in full | Must |
| DT-07 | Related records link to their own pages | Should |
| DT-08 | Tabs, when used, keep the most used one first and remember the last one | Nice |
| DT-09 | Not found or no access: says which and offers a way out | Must |
| DT-10 | A record being edited by someone else, or changed since it was opened, says so | Nice |
| DT-11 | Copy link or share, when people send records to each other | Nice |
