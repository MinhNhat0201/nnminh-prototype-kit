# Dashboard

Applies to: a home or overview page with numbers, charts, recent items and shortcuts.

| Code | Check | Level |
|---|---|---|
| DB-01 | The page answers the first question its users come with; the most important number or list is first | Must |
| DB-02 | Every number says what it counts, for which period, and when it was updated | Must |
| DB-03 | A change (up 12 %) says compared with what, and whether up is good | Should |
| DB-04 | Charts have a title, axis labels or units, and a legend when there are several series; colour is not the only way to tell series apart | Must |
| DB-05 | Each card links to the detail behind it | Should |
| DB-06 | The period or filter applies to every card, or each card says its own | Must |
| DB-07 | Empty data and loading per card, not one spinner for the page | Must |
| DB-08 | No more than about seven cards above the fold; the rest grouped or below | Should |
| DB-09 | Narrow widths stack the cards in order of importance | Should |
| DB-10 | A new user with no data sees what the dashboard will show and how to get there (`first-run.md`) | Should |
| DB-11 | Numbers in the locale format, rounded to what people need | Nice |
