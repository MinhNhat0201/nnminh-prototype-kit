# First run and empty product areas

Applies to: onboarding, a new workspace, the first visit to a part of the product with no data. Read with: `states-and-edge-data.md` S-01.

| Code | Check | Level |
|---|---|---|
| FR-01 | The empty area says what will be here, why it is worth it, and how to start, with one primary action | Must |
| FR-02 | People can reach real work in the first minute; a tour, when there is one, can be skipped and reopened | Must |
| FR-03 | Sample data or a template, when offered, is marked and easy to remove | Should |
| FR-04 | A setup checklist shows progress and each item links to the place it is done | Should |
| FR-05 | Onboarding asks only what changes the experience, and says why it asks | Should |
| FR-06 | Hints appear next to the thing they explain, once, and can be closed | Should |
| FR-07 | Inviting others, when the product is shared, is offered early | Nice |
| FR-08 | A returning user never sees the first-run screens again unless they ask | Must |
