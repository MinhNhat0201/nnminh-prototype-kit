# Notifications

Applies to: a bell or inbox, toasts, notification preferences.

| Code | Check | Level |
|---|---|---|
| NT-01 | The unread count is shown in text for screen readers and caps at a readable number ("99+") | Must |
| NT-02 | Each notification says who did what to which item, and when; it links to that item | Must |
| NT-03 | Read and unread look different, not by colour alone; "mark all as read" | Should |
| NT-04 | Grouped when many come from one source | Nice |
| NT-05 | Empty inbox says so in a friendly line, not a blank panel | Should |
| NT-06 | Toasts stay long enough to read (about five seconds or more), pause on hover or focus, and can be closed | Must |
| NT-07 | A toast with an action (Undo) stays until it is used or closed | Must |
| NT-08 | Errors are not toasts that disappear; they stay where the problem is | Must |
| NT-09 | Preferences let people turn off each kind, per channel (in app, email) | Should |
| NT-10 | Toasts do not cover the main action or each other | Should |
