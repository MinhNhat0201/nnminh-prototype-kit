From idea to developer handoff, with your design system

14 Claude Code skills that plan the work, build HTML, React or Vue prototypes with your design system, write the spec, put the flows on Figma and package everything for BA, QC and developers.

Install

Add the marketplace in Claude Code, then install the kit.

/plugin marketplace add MinhNhat0201/nnminh-prototype-kit

Quick start

Describe the job in plain words. brief picks the skill.

/kit:brief I want to prototype a task manager for our team
Skills
  • briefStartUnderstands a plain-language request and routes it to the right skill with a one-line plan.
  • kickoffStartSets up a project: config, design-system link, stack, first app and a smoke test.
  • adoptStartBuilds a base design system from the shadcn preset and your brand colour, with Material 3 structure for mobile and tablet.
  • definePlan and buildSplits requirements into units, writes questions for PM and BA, plans delivery waves with acceptance criteria.
  • prototypePlan and buildBuilds screens and flows from a request, a plan wave or a screenshot, using design-system components first.
  • annotateSpecifyWrites a Markdown spec per unit, with screen captures, pinned elements and styles mapped to token names.
  • wireflowSpecifyBuilds a flow board on Figma from screen captures and updates it in place, so shared links keep working.
  • mockupSpecifyRebuilds screens on Figma with auto layout, library components and variables, then checks the result automatically.
  • handoffDeliverOne zip for BA, QC and developers: spec, QC checklist, changelog, AGENTS.md and a scoped prototype.
  • shareDeliverDrafts the handoff email with Figma and demo links. Draft only; you send it.
  • reviewDesign systemRead-only audit of an app against the design system, with options to fix what it finds.
  • syncDesign systemBrings a new design-system version into your apps.
  • contributeDesign systemReviews local components and proposes the good ones to the design system, with two approval gates.
  • documentDesign systemWrites and maintains design-system docs and tokens.

How it works

  1. 1Set upadopt, kickoffBuild a base design system if you have none, then pick the language, stack and design system.
  2. 2DefinedefineTurn PM and BA requirements into open questions, delivery waves and a traceability matrix.
  3. 3PrototypeprototypeBuild screens with design-system components only. It asks before it creates a new component or page.
  4. 4Specifyannotate, wireflow, mockupWrite the spec with screen captures and token-level style notes. Put the flows and screens on Figma.
  5. 5Hand offhandoff, sharePack one zip for BA, QC and developers, and draft the email. It never sends it.

Point the kit at your design system

kit.config.json holds language, stack and apps. ds.json holds tokens, CSS bundle and theming.

Mix stacks in one repository

Each app can override the stack, so older HTML apps and new Vue apps live side by side.

Check contrast in light and dark

adopt checks every colour pair: 4.5:1 for text, 3:1 for icons and borders.
