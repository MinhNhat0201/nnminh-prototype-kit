Install

From idea to developer handoff, with your design system.

nnminh-prototype-kit is a free set of 14 Claude Code skills. It plans the work, builds HTML, React or Vue prototypes with your design system, writes the spec, puts the flows on Figma and packages everything for BA, QC and developers.

Install the kit Browse the skills

What the kit does

Design-system-aware skills for every step between a requirement and a handoff.

Any design system

Two files point the kit at your design system

Nothing is hard-coded. kit.config.json holds the language, stack and apps. A ds.json profile holds the token prefix, CSS bundle, theming and Figma libraries.

Handoff package

One zip, a reading path for each role

BA gets the spec and feature list, QC a checklist, developers AGENTS.md and the prototype. No screen images and no loose .js files, so mail filters let it through.

// layout of a handoff package
Design - <work item>.zip
  ├─ AGENTS.md         reading paths for BA, QC, developers
  ├─ README.md
  ├─ requirements/
  │   ├─ checklist-feature.csv
  │   ├─ checklist-qc.csv
  │   └─ changelog.md
  ├─ spec/             one Markdown file per unit
  └─ prototype/
Workflow

How the kit works

One path from a requirement to a handoff. Every step is a skill you can also run on its own.

  1. 1

    Set up the project

    Build a base design system if you have none. Then pick the language, stack and design system, and the first app is created for you.

    adoptkickoff
  2. 2

    Define the work

    Turn PM and BA requirements into open questions, delivery waves and a traceability matrix.

    define
  3. 3

    Build the prototype

    Screens use design-system components only. The kit asks before it creates a new component or page.

    prototype
  4. 4

    Write the spec

    Screen captures, pins and styles mapped to token names. Flows and screens go on Figma.

    annotatewireflowmockup
  5. 5

    Hand off

    Pack one zip for BA, QC and developers, and draft the email. The kit never sends it.

    handoffshare

    Frequently asked questions
    
      
    
      
    
        
    What is nnminh-prototype-kit?
    A Claude Code plugin with 14 skills that take a design from idea to developer handoff: requirement analysis, prototypes built with your design system, specs, Figma flow boards and one handoff package.
    
        
    Is it free?
    Yes. The kit is released under the MIT licence. The shadcn preset it ships with is derived from shadcn/ui and shadcn-vue, also MIT.
    
        
    Do I need a design system first?
    No. Without one, run adopt: it builds a base profile from shadcn with your brand colour, name, radius and font. If you have one, write a ds.json profile for it and kickoff links it.
    
        
    Which stacks does it support?
    HTML (the default, one file that opens anywhere), React and Vue. Each app can use its own stack, so they can live side by side in one repository.
    
        
    Does it send emails or publish anything on its own?
    No. share only drafts the handoff email for you to review and send. Skills save files; they do not commit, push or publish unless you ask.
    
        
    Do I need Figma?
    Only for wireflow, mockup and the optional Figma step of adopt, which need the Figma connector. Everything else works without it.
    
        
    Which languages can the documents be in?
    Replies and generated documents follow kit.config.json > language. English and Vietnamese ship with the kit; add a language by copying locales/en/ and translating the values.
    
        
    What do I need installed?
    Claude Code, Python 3.9+, Node 18+, Playwright with Chromium for screen capture, and Pillow for image optimisation.
