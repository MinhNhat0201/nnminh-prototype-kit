Handoff package

One zip, a reading path per role

BA gets the spec, QC a checklist, developers AGENTS.md and the prototype. pkg.py smoke test-opens the unpacked zip before you send it.

// layout of a handoff package
Design - <work item>.zip
  ├─ AGENTS.md         reading paths for BA, QC, developers
  ├─ README.md
  ├─ requirements/
  │   ├─ checklist-feature.csv
  │   ├─ checklist-qc.csv
  │   └─ changelog.md
  ├─ spec/             one Markdown file per unit
  └─ prototype/
People decide

Every decision has an owner

The kit proposes; a named person approves. Each decision is tracked until the build is verified.

  1. Observed
  2. Proposed
  3. Approved
  4. Implemented
  5. Verified

Gates: plan · design direction · new component · new page · DS proposal · accepted deviation

Checked, not just generated

One report separates failures from judgement calls

validate runs every screen, state and flow at three widths, light and dark. Known findings are waived with a reason; each is marked new or carried over.

Fail0errors, overflow, serious a11y, broken flows
Needs a human3touch targets, focus, visual changes
Skipped0always with a reason, never as passed
Workflow

How the kit works

Seven steps. Each one is a skill you can also run alone.

  1. 1

    Set up the project

    Pick the language, stack and design system. context keeps users, rules and decisions.

    adoptkickoffcontext
  2. 2

    Define the work

    Requirements become questions, delivery waves and a traceability matrix. Porting a live page? extract_rules.py drafts a parity checklist.

    define
  3. 3

    Explore directions

    Two to four directions, side by side. A person picks one, and the reason is kept.

    explore
  4. 4

    Build and check

    Screens use DS components; the kit asks before adding new ones. Built-in checklists cover accessibility, states, edge data, motion and heuristics.

    prototypevalidate
  5. 5

    Write the spec

    Screen captures with pins and token names, plus a Figma flow board. A new round updates the board in place.

    annotatewireflowmockup
  6. 6

    Hand off

    One zip and an email draft; the kit never sends it. No Figma links yet? Package as awaiting-figma, then relink.

    handoffshare
  7. 7

    Verify the build

    Compare the developers' build with the approved prototype. Each difference is a defect or an approved deviation.

    verify

    Frequently asked questions
    
      
    
      
    
        
    Is it free?
    Yes, under the MIT licence. Both presets are MIT too: shadcn derives from shadcn/ui and shadcn-vue, atelier from the author's own design system.
    
        
    Which stacks does it support?
    HTML (the default), React and Vue. Each app picks its own, so they can share one repository.
    
        
    Does it publish anything on its own?
    No. Skills save files and never commit, push or publish unless you ask.
    
        
    Do I need Figma?
    Only for wireflow, mockup and one optional adopt step. Everything else works without it.
    
        
    Which languages can the documents be in?
    English and Vietnamese ship with the kit, set in kit.config.json > language. To add one, copy locales/en/ and translate it.
    
        
    What do I need installed?
    Claude Code, Python 3.9+, Node 18+, Playwright with Chromium, and Pillow.
